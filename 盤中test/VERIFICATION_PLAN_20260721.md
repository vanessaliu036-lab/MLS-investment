## 1. 開盤 09:00 第一輪驗證（法人資料首跑）

### 1.1 觀察法人資料是否真的有餵進去

| 檢查 | 預期 | 失敗處置 |
|---|---|---|
| 至少 1 檔 `inst_warnings` 不是空 list | 法人 dict 真的餵到了 | `inst_chips` 沒組進 prefetch |
| 至少 1 檔 `inst_net_total` 是 int 不是 None | 三大法人合計有算 | `compute_inst_net_total` 邏輯 |
| UI 表格看得到「法人合計 XXX 張」 | 前端有接新欄位 | `test_page_wiring.build_rows` 沒回給前端 |

### 1.2 找一檔「法人合計賣超 > 3% 成交量」的真實股

- 用任意強勢股跌 2-5% 的（最容易觸發惜售象限 + 法人賣超）
- 預期：AI 講「法人合計賣超 -XXX 張」「不算惜售」「不建議抄底」
- **不該**出現「強惜售」字眼

### 1.3 找一檔「法人合計買超 + 分點吸籌」的真實股

- 條件：法人 `total > 0`、aflow > 0、change_rate < 0、intensity ≥ 10
- 預期：AI 講「法人買盤進場（合計 +XXX 張）」「配合分點吸籌 XX%」「強惜售」「抄底候選、緊停損」

### 1.4 找一檔「法人資料沒抓到」的股

- 條件：3 個法人欄位都 None
- 預期：AI 講「法人資料未接入」「先觀察法人動向」
- **不該**出現「強惜售」字眼

## 2. 盤中 09:30-12:00 第二輪驗證（觸發類型壓力測試）

### 2.1 法人合計賣超屏蔽觸發

- 鎖定：法人 `total < 0` 且 `abs(total) > total_volume × 0.03`
- 觀察：`inst_sell_blocks_absorb = True` 出現的股
- AI 輸出：必須有「不算惜售」「不建議抄底」任一字眼

### 2.2 法人數據 hard_block 觸發

- 鎖定：單一法人 `|val| > total_volume`（數量級不可能）
- 預期：UI 顯示 🛑 警告、AI 講「硬擋」「不可信」「先別碰」
- ⚠️ 實務上正常大型股不會觸發，除非資料源錯（這反而是好事，能第一時間抓 bug）

### 2.3 方向矛盾觸發

- 鎖定：法人 `total < 0` 但 `inst_foreign > 10000`（合計賣超但外資買超大）
- 預期：UI 顯示 ⚠️「法人合計賣超 -XXX 張，外資 卻買超 +XXX 張」

### 2.4 跌停觸發

- 鎖定：`change_rate <= -9%`
- 預期：極端價優先，AI 講「逼近跌停」「訊號降級不可信」「先別碰」
- 不論法人資料是什麼，跌停本身就要觸發

## 3. 收盤 13:30 第三輪驗證（覆蓋率 + edge case）

### 3.1 全池覆蓋率

- 跑 `passes_filters` 全 universe，計算：
  - `inst_warnings != []` 的股數 / 總股數（預期 > 50%，多檔會有輕微警告）
  - `inst_hard_block = True` 的股數（預期 0，正常情況）
  - `inst_sell_blocks_absorb = True` 的股數（看當天賣壓程度）

### 3.2 真攻擊股回歸

- 鎖定：aflow > 0 + 漲 + 法人合計買超
- 預期：AI 講「真攻擊」「追漲候選」

### 3.3 假紅股回歸

- 鎖定：aflow < 0 + 漲 + 法人合計賣超
- 預期：AI 講「假紅」「衝高留意拉回、別追」

### 3.4 休息股回歸

- 鎖定：aflow < 0 + 跌
- 預期：AI 講「量能休息」「沒訊號、略過」

## 4. 失敗處置對照表

| 症狀 | 可能原因 | 處置 |
|---|---|---|
| 全部股的 `inst_net_total` 都是 None | `inst_chips` 沒餵到 / 格式錯 | 查 `twse_fetch` / `prefetch` 接線 |
| 全部都 `inst_sell_blocks_absorb = True` | 法人合計門檻太寬（3% 對某些小型股太嚴） | 觀察，若太多 → 調到 5% |
| 真實大型股被 `hard_block` | 單一法人當日買賣超 > 成交量（不合理，但實際可能因周轉率高） | 調 `INST_ABS_HARD_RATIO` |
| AI 從來不講「強惜售」 | 法人資料 100% 有但合計都是賣超（或合計=0） | 看是真實情境還是資料錯 |
| AI 講「強惜售」但法人合計是賣超 | `inst_sell_blocks_absorb` 沒生效 / 被 hard_block 蓋過 | 跑單元測試 `test_case_A` 重現 |
